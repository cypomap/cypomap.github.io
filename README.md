<h1>CypoMap — Cyprus POTA (SOTA and LLOTA coming soon) Interactive Map</h1>

<p>
CypoMap is an interactive mapping tool designed for radio amateurs, hikers, and explorers who want clear, accurate, and practical boundary information for <strong>Cyprus POTA (Parks on the Air)</strong> locations and <strong>Natura 2000</strong> protected areas.
</p>

<p>
It provides a fast, lightweight, mobile‑friendly map showing:
</p>

<ul>
  <li>All Cyprus POTA parks</li>
  <li>Natura 2000 boundaries</li>
  <li>Colour‑coded POTA markers</li>
  <li>Click‑to‑highlight park boundaries</li>
  <li>MultiPolygon support</li>
  <li>Easy visibility of roads, paths, and access points</li>
  <li>GeoJSON‑driven boundary shading and highlighting</li>
</ul>

<p>
CypoMap is built to be used <strong>in the field</strong>, “in anger”, where clarity and speed matter more than fancy UI design.
</p>

<hr>

<h2>Why CypoMap Exists</h2>

<p>
Cyprus has many beautiful parks and protected areas, but finding accurate boundaries, access roads, and activation spots can be difficult. Existing tools are either incomplete, outdated, or not optimised for real‑world use.
</p>

<p>
CypoMap solves that by providing:
</p>

<ul>
  <li>A simple, fast, no‑nonsense map</li>
  <li>Accurate GeoJSON boundaries</li>
  <li>Clear visual highlighting</li>
  <li>A practical tool for POTA activators and nature enthusiasts</li>
</ul>

<hr>

<h2>Technology Used</h2>

<ul>
  <li>Leaflet.js for mapping</li>
  <li>GeoJSON for boundaries</li>
  <li>Pure JavaScript (no frameworks)</li>
  <li>GitHub Pages for free hosting</li>
  <li>No backend, no server, no database</li>
</ul>
